# Adobe Stock

- Syarat gambar minimal 4 MP.
- Metadata lewat CSV: judul maksimal 70 karakter, maksimal 49 kata kunci (yang terpenting di awal).
- Setiap berkas wajib dijawab "Recognizable people or property?" sebelum bisa dikirim. Untuk banyak berkas: Select All → No → Save work (hanya bila memang tidak ada orang/properti yang dikenali).
- Konten AI generatif wajib ditandai sesuai aturan Adobe; tanpa nama seniman, merek, atau tokoh nyata di prompt maupun metadata.
- Unggah per kelompok kecil. Tab "New" yang berisi lebih dari ±80 berkas membuat portal sangat lambat dan otomasi macet. Kirim kelompok itu dulu, baru unggah lagi.
- Tombol Submit ke review ditekan pemilik sendiri; otomasi tidak menekan Submit.
- Profil login peramban dan ID kontributor tidak dipublikasikan.
